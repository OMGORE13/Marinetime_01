# Maritime Logistics App

A comprehensive interactive web platform for tracking cargo, ships, customs approvals, and multimodal transport options.

## Quick Start

### 1. Launch directly:
Double-click `start.bat` in this folder, or run:
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 2. Build for production:
```bash
npm run build
```
This generates the optimized production bundle in the `dist/` directory.

### 3. Preview production build:
```bash
npm run preview
```

## Tech Stack
- **React 19**
- **TypeScript**
- **Vite 8**
- **Tailwind CSS 4**
